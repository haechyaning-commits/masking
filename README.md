# 공공감사포털 업로드 전 개인정보 마스킹 도구 (MVP)

감사데이터를 공공감사포털에 업로드하기 전, 문서에 포함된 **정형 개인정보(주민등록번호·전화번호·이메일·계좌번호)** 를 정규식으로 자동 탐지하고, 사람이 최종 확인한 뒤 마스킹된 PDF로 내려받는 **브라우저 단독 실행 도구**입니다.

> **1차 필터링 도구**입니다. 완전 자동화가 아니며, 반드시 사람의 최종 육안 검토를 거쳐야 합니다.

## 특징

- **설치·서버·인터넷 불필요**: 순수 HTML/JS이며 pdf.js·pdf-lib를 프로젝트에 함께 포함(벤더링)했습니다. 파일이 서버로 전송되지 않고 브라우저 안에서만 처리됩니다. (사내 PC 설치 제약 및 CDN 차단 환경 대응)
- **규칙 기반 자동 탐지**: 주민등록번호, 전화번호, 이메일, 계좌번호(추정) 정규식 패턴 매칭
- **사람 최종 확인 UI**: 실제 페이지 위에 탐지 박스를 겹쳐 표시하고, 항목 클릭 또는 카테고리별로 포함/제외 토글
- **두 가지 마스킹 방식**:
  - **완전 제거(권장)** — 페이지를 이미지로 평면화하여 텍스트 레이어를 제거. 마스킹된 글자가 추출·복사되지 않습니다.
  - **검은 박스만** — 원본 위에 검은 사각형만 그림. 텍스트 레이어는 유지되지만 **박스 아래 원본 글자가 그대로 남아 추출될 수 있습니다.**

## 사용 방법

1. `index.html`을 브라우저로 엽니다. (인터넷 연결 불필요 — 필요한 라이브러리가 `vendor/`에 포함되어 있음)
   - pdf.js worker는 `file://`에서 로드가 막히는 브라우저가 있으므로, **로컬 서버로 여는 것을 권장**합니다: 프로젝트 폴더에서 `python -m http.server` 실행 후 `http://localhost:8000` 접속.
2. PDF를 업로드(드래그 또는 클릭)합니다.
3. 자동 탐지된 박스를 검토합니다. 오탐은 클릭하여 제외, 카테고리 전체는 좌측 체크박스로 일괄 토글.
4. 마스킹 방식을 고르고 **마스킹 PDF 다운로드**를 누릅니다. (`원본이름_masked.pdf`)
5. 내려받은 파일을 **육안으로 최종 확인**한 뒤 포털에 업로드합니다.

## 기술 스택

| 역할 | 라이브러리 |
|---|---|
| PDF 텍스트/좌표 추출 및 렌더링 | [pdf.js](https://mozilla.github.io/pdf.js/) |
| PDF 편집(마스킹) 및 저장 | [pdf-lib](https://pdf-lib.js.org/) |
| 실행 환경 | 브라우저 단독 (HTML/CSS/JS) |

## 파일 구조

```
index.html            진입점 / UI 구조
css/styles.css        스타일
js/detectors.js       정규식 기반 개인정보 탐지 로직
js/app.js             PDF 처리 · 렌더링 · 검토 UI · 마스킹 생성 조율
vendor/               포함된 라이브러리 (오프라인 실행용)
  pdf.min.js          pdf.js
  pdf.worker.min.js   pdf.js 워커
  pdf-lib.min.js      pdf-lib
```

## 지원 범위 (MVP)

**지원**
- 텍스트 레이어가 있는 PDF (OCR 없이 텍스트 추출 가능한 문서)
- 정형 개인정보: 주민등록번호, 전화번호, 이메일, 계좌번호(추정 패턴)

**미지원 (이번 MVP 범위 아님)**
- **비정형 정보**(이름·주소·소속 등): 문맥 판단 필요 → 향후 한국어 NER 도입 검토
- **스캔본(이미지) PDF**: 텍스트 추출 불가 → OCR 필요
- **HWP 파일**: 별도 PDF 변환 후 처리

## 한계 및 주의사항

- **정규식 오탐/누락**: 공백·특수기호가 섞여 형식이 어긋난 번호는 놓칠 수 있고, 형태가 비슷한 일반 숫자를 오탐할 수 있습니다. → 반드시 사람이 최종 검토.
- **좌표 근사**: 문자폭을 균등하다고 가정해 마스킹 박스 위치를 근사합니다. 세로쓰기나 회전된 페이지는 정확도가 떨어질 수 있습니다.
- **"검은 박스만" 방식의 위험**: 검은 사각형은 시각적 가림일 뿐, PDF 텍스트 레이어의 원본 글자는 남습니다. 실제 개인정보 보호를 위해서는 **완전 제거(이미지화)** 방식을 사용하세요.
- 다운로드한 결과물은 **업로드 전 반드시 육안으로 재확인**하세요.

## 개인정보 처리 안내

업로드한 PDF와 마스킹 결과는 **브라우저 내에서만 처리**되며 외부 서버로 전송·저장되지 않습니다.
