규칙 기반 자동 탐지 · 사람 최종 확인 · 브라우저 단독 실행 (MVP)

데이터 미전송 · 브라우저 내 처리

규칙으로 자동 탐지한 번호류입니다. 오탐은 페이지에서 박스를 클릭해 제외하세요.

마스킹 문자 (번호류 전용 — 이름·직접지정은 사람마다 다른 기호가 자동 배정됩니다)

자동으로 못 잡은 이름·기관은 모드를 켠 뒤 단어를 클릭하면 마스킹됩니다. 표·도장 등 넓은 영역은 드래그하세요.

방식

추가한 항목은 다시 클릭하면 삭제됩니다.

포함된 마스킹0건

결과는 이미지화로 저장되어 원본 글자가 함께 제거됩니다(마스킹 부분 추출 불가).

마스킹 완료 ⬇ 마스킹 PDF 다운로드

다운로드가 안 되면(미리보기 전용 환경) 첨부된 독립 실행 파일에서 저장하세요.

⚠️ 이 도구는 1차 필터링 도구입니다. 자동 탐지는 오탐·누락이 있을 수 있으니, 다운로드한 파일을 반드시 육안으로 최종 확인한 뒤 업로드하세요.
  • 파일이 서버로 전송되지 않습니다. 업로드·탐지·마스킹 모두 브라우저 안에서만 처리됩니다.
  • 코드에 네트워크 전송(업로드·fetch 등)이 전혀 없습니다. 필요한 라이브러리도 파일 안에 포함(외부 CDN 없음).
  • 인터넷을 꺼도 동작합니다. → 데이터가 밖으로 나가지 않는다는 증거입니다. (네트워크 차단 후 사용해 직접 확인하세요.)
  • 마스킹된 부분은 결과에서 추출·복사되지 않습니다(이미지화로 원본 글자 제거).
  • 원본 작성자·제목 등 메타데이터도 제거됩니다.
  • 가장 안전하게: 실데이터는 내려받은 파일(로컬)로 사용하세요.

PDF를 업로드하면 개인정보 후보가 자동으로 탐지되어 페이지 위에 표시됩니다.
